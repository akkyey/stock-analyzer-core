## 1. エグゼクティブサマリ

本日（2026-10-06）、**Stock Analyzer Core `v1.3.1`** の正式リリースおよび関連資材の同期・検証を完了しました。

本リリースは、当初の目的であった「同梱財務データ（シード）の欠損率改善・決算期更新」に加え、**ユーザーからの法的・規約的懸念（EDINET / yfinance の規約遵守・再配布リスク）および運用の持続性（データ陳腐化対策）に関する指摘を全面的に反映**した重要マイルストーンです。

### 主要な達成事項
1. **同梱財務データの法的・規約的クレンジング（完全安全化）**:
   - yfinance 等の出所未確認列（16 列）をすべて `None` 化し、EDINET 公共データ利用規約（PDL1.0）に基づく公式開示データのみに限定。
   - 識別子 **`e3f635c30bb9`**（3,926 銘柄）としてシードを再確定。
2. **利用者が自前で財務データをフル再構築できる仕組みの提供**:
   - 金融庁 EDINET API から直接全社データを自動生成するスクリプト `scripts/build_fundamentals_seed.py` を整備。
   - Google Colab ノートブックに「自前再構築セル（フォームUI）」を追加し、マニュアル化。
3. **Colab 実機による稼働検証（PASS）**:
   - 既存 Google Drive DB に対し、新しい安全化シードが安全に反映され、全 3,846 銘柄のスクリーニング（所要時間 18.9 分）が正常終了することを確認。
4. **ノートブック UI の刷新（コードセルのフォーム化）**:
   - 全コードセルをデフォルト折りたたみ（`cellView: form`）とし、利用者がプログラムを開かずに直感的に実行できる UI に統一。
5. **商品化・有償化構想の整理**:
   - 将来的な「Zenn / note 併売」「GitHub Actions 自動化ワークフロー同梱」「コアエンジンとノートブックの分離」に向けた設計方針を整理。

## 2. 課題と対応内容の詳細

> **注（2026-10-09）**: 課題 2 の「自前再構築セル」と利用ガイド 7-5 の手順は、出力をパイプラインが読まず機能しなかったため、削除・書き換え済み。現在は Step 0 の `refetch_edinet_year`（過去 1 年分の取り直し）に置き換わっている。詳細は [オーナー変更のレビューと対応記録](v1_3_1_owner_changes_review_20261009.md) を参照。

### 課題 1: 同梱財務データの再配布リスク（外部 API 規約懸念）
- **背景**: リポジトリに同梱されている `fundamentals_seed.parquet` の一部列に、yfinance に由来すると推測される列（`operating_cf`, `current_ratio` 等）が含まれていた。yfinance 等は商用再配布やリポジトリ同梱を許諾していない可能性が高い。
- **対応**:
  - レビュー票 T-01 に基づき、**出所未確認の 16 列をすべて `None`（空）にする処置** を採択・実施。
  - スクリーニングの足切りで使用される `operating_cf` も、空の場合は安全に判定をスキップする仕様となっており、システム動作に破綻がないことを検証。
  - 新シードフィンガープリント: **`e3f635c30bb9`**。
  - README および利用ガイドに、EDINET 公共データ利用規約（PDL1.0）に基づくクレジット表示（作者: `akkyey`、出典表示、加工表示）を明記。

### 課題 2: 同梱データの陳腐化懸念と自給自足の要望
- **背景**: 「配布から時間が経つとデータが古くなって使えなくなる」「開発者が毎年更新を忘れるリスクがある」という懸念。
- **対応**:
  - 利用者が自分自身の EDINET API キー（無料取得可能）を使って、いつでも全上場銘柄の有報・半期報を自動収集・パース・シード作成できるスクリプト `scripts/build_fundamentals_seed.py` を実装。
  - 生成時にも自動で「出所未確認列の安全化（空化）」を適用し、利用者が作成したデータも安全規格を満たすように設計。
  - 利用ガイド `docs/guides/colab_user_execution_guide.md` にセクション 7-5（自前再構築手順）を追加。
  - Colab ノートブック末尾に、パラメータ入力式の自前再構築セルを配置。

### 課題 3: Colab ノートブックの視認性悪化（プログラムコードの露出）
- **背景**: 機能追加に伴い、コードセルの中身が露出してノート全体が長くなり、操作しづらくなっていた。
- **対応**:
  - 全コードセルに `# @title` を付与し、セルメタデータに `"cellView": "form"` を設定。
  - すべてのプログラムコードがデフォルトで閉じ、タイトル行やパラメータ入力欄のみが表示されるクリーンな UI へ刷新。
