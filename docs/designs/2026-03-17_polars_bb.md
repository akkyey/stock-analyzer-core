# Design Memo: Polars & Bollinger Bands Integration

## Objective
株式システムの演算部を Polars に移行し、ボリンジャーバンド指標を追加してパフォーマンスと精度の向上を図る。

## System Architecture
- **Engine Selection**: `config.yaml` の `use_polars: true` を参照。
- **PolarsEngine**: `LazyFrame` と `Expression` を使用し、欠損カラムがあっても動作する堅牢な演算ロジック。
- **BB Scoring**: ±2σ を越境した際の動的なスコアリング（+10pt / -5pt）。

## Verification Results
- 演算時間: Pandas(V2) 約6.4秒 -> Polars(V3) 約51ms。
- バリデーションエラー対策: `config_schema.py` に `use_polars` を追加し、データ欠落を防止。
